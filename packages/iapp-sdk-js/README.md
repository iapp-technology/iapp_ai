# iapp-ai (JavaScript / TypeScript SDK)

JavaScript/TypeScript SDK for the [iApp AI Marketplace APIs](https://iapp.co.th) — Thai OCR, eKYC, NLP, speech and more. The JS counterpart of the Python [`iapp-ai`](https://pypi.org/project/iapp-ai/) package.

> ⚠️ **Status: scaffold (v0.1.0).** Client core and API methods are being added — see the repo's SDK-JS plan.

## Requirements

- Node.js >= 18 (uses the built-in `fetch` — zero runtime dependencies)

## Install

```bash
npm install iapp-ai
```

## Quickstart

```ts
import { api } from "iapp-ai";

const client = api("YOUR_API_KEY");
// API methods coming soon (Phase 3)
```
